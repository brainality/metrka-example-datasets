# Changelog

## [Unreleased]

## [1.1.0] - 2026-09-20

- Updated the pinned `metrka-core` wheel to version 1.1.0.
- Added the least-privilege `metrka_operator` role and local
  `METRKA_OPERATIONS_DSN` configuration for Core governance commands.

## [1.0.0] - 2026-08-22

First public example release.

- Added a complete Gapminder HTTP-to-Silver workspace.
- Added disposable local PostgreSQL infrastructure.
- Added configuration contract tests and an end-to-end GitHub Actions run.
- Pinned both the `metrka-core` wheel and the upstream dataset revision.
