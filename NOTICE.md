downloaded dataset.

and contributors. It is an excerpt of data from Gapminder and is published by
that project under CC0. The configured URL is pinned to Git commit
`391b5a40d3574c3b89d889dd7d72f7f3fdb4a70c` so the tutorial input cannot change
without a reviewed configuration change.
